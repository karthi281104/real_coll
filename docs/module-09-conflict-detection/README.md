# Module 9 — Conflict Detection & Resource Reservation

## 1. Architectural Role

Module 9 evaluates the future trajectories generated by Module 8 across all pairs of trains in the railway network to identify any spatial-temporal collision hazards.

Additionally, Module 9 incorporates the **Resource Reservation Manager**, which manages exclusive temporal occupancy leases on critical infrastructure (railway junctions, platform tracks, and directional track blocks) to guarantee collision-free routing.

## 2. The Four Primary Conflict Types

| Conflict Type | Physical Scenario | Mathematical Condition |
|---|---|---|
| **Head-On** | Two trains operating on the same track traveling toward one another from opposite ends. | Common track; $\Delta p_A \cdot \Delta p_B < 0$ or $v_A \cdot v_B < 0$; separation $\le d_{sep} + \sigma_A(t) + \sigma_B(t)$. |
| **Rear-End** | Faster train following slower train on the same track and closing the gap. | Common track; identical travel direction; closing rate $\Delta v > 0$; separation $\le d_{sep} + \sigma_A(t) + \sigma_B(t)$. |
| **Junction** | Two trains approaching a converging track switch/junction from different feeder tracks. | Trajectories cross common junction Node $N$; arrival time delta $|t_A^{cross} - t_B^{cross}| \le t_{sep}$ ($5.0\text{ s}$). |
| **Platform** | Multiple trains scheduled to occupy the same station platform track simultaneously. | Common platform Node or platform track; dwell intervals overlap within clearance window $t_{clear}$ ($2.0\text{ s}$). |

## 4. Algorithmic Formulation

### 4.1 Analytical Interval Solver for Same-Track Trajectories

Rather than sampling coarsely at discrete 5s/10s steps (which risks missing high-speed collisions that occur between prediction points), Module 9 treats each trajectory segment $[t_0, t_1]$ as a continuous linear interval:
- Relative position: $\Delta p(t) = \Delta p_0 + \dot{p} \cdot t$
- Protected dynamic separation: $m(t) = d_{min} + \sigma_A(t) + \sigma_B(t) = m_0 + \dot{m} \cdot t$

A collision condition occurs when $\Delta p(t)^2 \le m(t)^2$. This is expanded into a standard quadratic:
$$f(t) = q_a t^2 + q_b t + q_c \le 0$$
where:
$$q_a = \dot{p}^2 - \dot{m}^2$$
$$q_b = 2(\Delta p_0 \dot{p} - m_0 \dot{m})$$
$$q_c = \Delta p_0^2 - m_0^2$$

By solving the discriminant $\mathcal{D} = q_b^2 - 4 q_a q_c$, exact critical roots $t_1, t_2$ are identified analytically. The solver extracts:
- `firstConflictTime`: The exact second when protected separation is breached.
- `lastConflictTime`: The second when trains clear one another.
- `minimumSeparation`: The closest point of approach over the interval.

### 4.2 Exact Node Crossing Time Calculation

For junction and platform conflicts, discrete horizon states $[s_{i-1}, s_i]$ that cross a node boundary are interpolated with bounded precision:
$$t_{cross} = t_{prev} + \frac{L_{track} - p_{prev}}{v_{prev}}$$
If $t_{cross} \in [t_{prev}, t_{curr}]$, $t_{cross}$ is used as the high-precision crossing timestamp; otherwise, it falls back cleanly to $t_{curr}$.

If $|t_{cross, A} - t_{cross, B}| \le t_{sep}$, a `ConflictType::Junction` event is generated.
